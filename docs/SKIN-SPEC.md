# 双皮肤（干练 / 工场）

人自己选视图。机器级 `AppSettings.skin`，进 catalog，不进仓内 `project.json`。

对照 [Terafab](https://www.terafab.ai/)：深底、大数字、流程工位。不抄它的文案，不把工区做成芯片厂宣传页。

## 闭集

| 值 | 给人看 | 行为 |
|---|---|---|
| `lean`（默认） | 干练 | 纸面工区。森林上方同样有 worktree 工位（苔痕、不转）。 |
| `forge` | 工场 | 深色晶圆工位。同一套 `WorktreeDeck`，地板吃 `depth`。三主视图不变。 |

其它值加载时回落 `lean`。

## 写在哪

设置页两张卡片，点选即保存。CLI：`workzoon settings --skin forge --actor human`。Swift 设置里同一选择。

`motion: off` / 系统减弱动效时，工位晶圆不转，视差变量清零。换页 / 接住 / 证据跳动见 [MOTION-SPEC.md](./MOTION-SPEC.md)。`depth` 只是七个动词之一。

## 工场交互（视差）

工场皮肤在中栏 `.content` 上读滚动，在壳上读指针，写成 `--px --py --scroll`（-1…1 / 0…1）。`--scroll` 按前 420px 行程归一，不是整页 0–底；中栏不够滚时，滚轮仍推虚拟行程。指针/滚动插值，不跟手跳。

| 层 | 跟谁 | 幅度 |
|---|---|---|
| 远景光晕 | 指针 + 反方向滚 | 大 |
| 网格 | 滚慢、指针轻 | 中 |
| 地平线 | 反方向滚 | 中 |
| 近景雾 | 指针反向 + 同向滚 | 小 |
| 工场地板 | 指针透视 + 轻滚 | 工位跟手 |
| 工序条 | 指针 | 浅 |
| 仪表数字 | 上滚略退后、略放大 | 浅 |
| 列表行 | 几乎不动 | 可读 |

干练皮肤不写这些变量，不加层。不引 Three.js / GSAP。不第四主视图。不劫持中栏滚动。
