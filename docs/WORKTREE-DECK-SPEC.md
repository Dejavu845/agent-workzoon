# Worktree 工位（全部分支）

检出的 worktree 是人掌控的四资产之一。森林上方用同一套 `WorktreeDeck` 工位，两皮肤共用结构，不第四主视图。甲板只放活树：git 仍挂着、或 `status: active` 且目录还在，并且不是仓根。`archived` 的登记路径和主 checkout 不占工位。掌控四格和侧栏的树数跟甲板同一口径，不把仓根算进去。

## 给人看

每个工位只写磁盘真相：分支、短路径、`@sha12`、任务题、钉的版数、卫生、是否 HEAD。有任务卡时多写一句派生「下一手 · 动词」（`loopForLane`，与对照同一读层）。没有自报 %。点卡选中并打开对照，不换主视图。

指针在工位上时，晶圆跟 `--lx --ly`（`useLocalPointer`）。选中走 `receive`。`motion: off` 不跟手、不转。

## 皮肤

| 皮肤 | 工位 |
|---|---|
| 干练 | 纸面、苔痕轨、不转 |
| 工场 | 深底晶圆、选中才转、地板仍吃 `depth` |
